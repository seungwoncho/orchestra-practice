1기초 개념

문제를 풀기 전에 꼭 필요한 최소한의 약속들

1-1. 산과 염기는 "무엇을 내놓느냐"로 구별한다

물에 녹아 수소 이온(H+)을 내놓는 물질이 산, 수산화 이온(OH−)을 내놓는 물질이 염기입니다. 산의 공통 성질은 H+ 때문에, 염기의 공통 성질은 OH− 때문에 나타납니다.

HCl → H+ + Cl−
H2SO4 → 2H+ + SO42−
CH3COOH → H+ + CH3COO−
NaOH → Na+ + OH−
KOH → K+ + OH−
Ba(OH)2 → Ba2+ + 2OH−
⚠️ 가수(價數)에 주의! H2SO4 1개는 H+를 2개, Ba(OH)2 1개는 OH−를 2개 내놓습니다. 심화 문제의 함정은 대부분 여기서 나옵니다.

pH가 7보다 작으면 산성, 7이면 중성, 7보다 크면 염기성. 수용액 속 H+가 많을수록 pH가 작다.

1-3. 중화 반응 = H+와 OH−가 만나 물이 되는 반응

전체 반응식 : HCl + NaOH → NaCl + H2O
알짜 이온 반응식 : H+ + OH− → H2O  (1 : 1로 반응)
구경꾼 이온 : 반응에 참여하지 않는 이온 (예: Na+, Cl−, K+, NO3−). 넣은 양만큼 그대로 쌓인다.
염 : 산의 음이온 + 염기의 양이온이 만든 물질 (NaCl, KNO3, BaSO4 …). BaSO4, CaCO3처럼 물에 녹지 않으면 앙금으로 가라앉는다.
중화점 : 산의 H+ 수 = 염기의 OH− 수가 되어 모두 반응한 지점. 이때 생성된 물의 양이 최대 → 발생한 열(중화열)도 최대 → 온도가 가장 높다.

1-4. 생활 속 중화 반응

속 쓰릴 때 제산제위산(HCl) + 수산화 마그네슘 등
산성 토양에 석회 뿌리기산성 토양 + 석회(염기성)
생선 요리에 레몬즙비린내 성분(염기성) + 레몬즙(산)
벌레 물린 곳에 암모니아수개미산(폼산) + 암모니아수
산성화된 호수에 석회 가루산성비 + 석회
비누 사용 후 산성 린스비누(염기성) + 린스(약산성)

✅ 개념 체크 OX (눌러서 정답 확인)

  • 1. HCl(aq)에 NaOH(aq)을 넣으면 Cl−의 수는 줄어든다.
    X — Cl−은 구경꾼 이온이라 수가 일정하다. 줄어드는 것은 H+.
  • 2. 페놀프탈레인 용액이 무색이면 그 용액은 산성이다.
    X — 중성에서도 무색. "산성 또는 중성".
  • 3. H2SO4 1개를 완전히 중화하려면 NaOH 2개가 필요하다.
    O — H2SO4는 H+를 2개 내놓는다.
  • 4. 중화점에서 혼합 용액 속 이온은 하나도 없다. (HCl + NaOH)
    X — Na+, Cl−이 남아 있다. 이온 수가 0이 되는 건 앙금이 생기는 H2SO4 + Ba(OH)2 같은 경우.
  • 5. 중화 반응은 열을 방출하는 반응이다.
    O — 중화열. 생성된 물의 양이 많을수록 열이 많이 난다.

2-4. 중화열과 온도 그래프

(가) 총 부피 고정 — 온도 변화 ∝ 생성된 물의 양. 왼쪽 직선과 오른쪽 직선의 교점(꼭짓점)이 중화점. 꼭짓점의 부피 비로 농도 비를 구한다.
(나) 계속 넣기 — 중화점에서 최고 온도. 이후엔 더 이상 열이 나지 않고, 차가운 용액이 섞여 들어와 온도가 서서히 내려간다.

조건: 혼합 전 두 용액의 온도가 같고, 용액의 밀도·비열이 같으며, 열 손실은 무시한다(문제의 "단서"로 항상 주어짐).

2-5. 액성별로 남는 이온 (HCl + NaOH)

혼합 용액존재하는 이온이온 종류 수가장 많은 이온
산성H+, Cl−, Na+3Cl− (= H+ + Na+)
중성Cl−, Na+ (같은 수)2—
염기성Na+, Cl−, OH−3Na+ (= Cl− + OH−)
전하 균형 — 용액 전체는 전기적으로 중성이므로 (양이온의 전하 합) = (음이온의 전하 합). 산성일 때 H+ + Na+ = Cl−, 그래서 Cl−이 가장 많다.

S1

구경꾼 이온은 "자(ruler)"다

Cl−, Na+, SO42−(Ba2+가 없을 때)는 반응하지 않으므로 넣은 양 그대로 남습니다. 모형이나 그래프에서 구경꾼 이온의 수를 보면 각 용액을 얼마나 넣었는지 바로 복원됩니다.

Cl⁻ 수 = 넣은 HCl의 양  |  Na⁺ 수 = 넣은 NaOH의 양

언제? 이온 모형이 주어질 때, "처음 용액에 들어 있던 이온 수"를 물을 때 (01, 07)

S2

미지수 a, b — 이온 수 = (단위 부피당 이온 수) × 부피

HCl(aq) 1 mL당 H+ a개, NaOH(aq) 1 mL당 OH− b개로 두면 모든 표 문제가 일차방정식이 됩니다. 구하는 것은 대부분 a : b라는 비뿐이므로, 상댓값 그대로 계산해도 됩니다.

중화 조건 : a × V산 = b × V염기  →  a : b = V염기 : V산

언제? 부피가 다른 혼합 용액 여러 개가 표로 주어질 때 (04, 05, 08)

S3

min 규칙 — 생성된 물 = 적은 쪽

H+와 OH−는 1 : 1로 반응하므로 생성된 물 분자 수는 min(H+ 수, OH− 수), 남는 이온은 많은 쪽 − 적은 쪽입니다.

H₂O = min(H⁺, OH⁻)  |  남은 이온 = |H⁺ − OH⁻|

언제? "생성된 물 분자 수", "중화열", "온도"를 비교할 때 (01, 04, 07, 08)

S4

전체 이온 수 패턴 — "중화점까지 일정, 이후 증가"

HCl + NaOH, H2SO4 + NaOH처럼 앙금이 없으면, 중화점 전에는 H+ 1개가 빠지고 Na+ 1개가 들어와 전체 이온 수가 처음 그대로. 1가 + 1가 조합에서는 다음 공식이 성립합니다.

전체 이온 수 = 2 × max(넣은 H⁺ 수, 넣은 OH⁻ 수)

언제? 전체 이온 수 그래프·표가 주어질 때, 꺾이는 점에서 중화점을 찾을 때 (02, 03, 04)

S6

이온 모형 판별 — 종류 수, 대소 관계, 귀류법

  • 종류 수 : (1가 산 + 1가 염기) 중성이면 2종, 산성·염기성이면 3종.
  • 대소 관계 : 산성이면 산의 음이온이 최다, 염기성이면 염기의 양이온이 최다 (전하 균형).
  • 귀류법 : 산성/염기성 중 하나를 가정 → 전하 균형이나 개수 조건과 모순이면 나머지가 정답.

언제? ●▲■ 같은 기호로 이온을 숨긴 모형 (01, 07)

S7

혼합 용액끼리 섞기 — 남은 것끼리만 다시 반응

산성 용액 (가)와 염기성 용액 (나)를 섞으면 (가)에 남은 H+와 (나)에 남은 OH−만 반응합니다. 처음부터 전부 다시 계산할 필요가 없어요.

(가) H⁺ 3 + (나) OH⁻ 1 → H⁺ 2 남음 → 산성

언제? "(가)와 (나)를 모두 혼합한 용액" 보기 (08)

S8

가수와 앙금 — 2가 이온은 쪼개서 센다

  • H2SO4 : H+ 2 : SO42− 1  /  Ba(OH)2 : Ba2+ 1 : OH− 2
  • Ba2+ + SO42− → BaSO4↓ : 이온 수가 두 군데서 줄어 전체 이온 수가 감소, 중화점에서 0.
  • "분자 수"와 "이온 수"를 구분 : H2SO4 N개 → 이온 3N개.

언제? H2SO4, Ba(OH)2, 전구 밝기·전류 문제 (06, 07)

S9

온도 그래프 — 꼭짓점 = 중화점, 기울기 비 = 농도 비

총 부피가 일정하면 ΔT ∝ 생성된 물. 왼쪽 직선은 산이 모두 반응하는 구간(기울기 ∝ a), 오른쪽 직선은 염기가 모두 반응하는 구간(기울기 ∝ b)입니다. 측정점이 꼭짓점에 없으면 두 직선을 연장해 교점을 구하세요.

꼭짓점 (V산, V염기) → a : b = V염기 : V산

언제? 혼합 용액의 최고 온도·온도 변화 그래프 (05). 총 부피가 다르면 ΔT 비교 시 부피도 고려!

S10

"전체" vs "단위 부피당" — 마지막 함정 체크

보기에 단위 부피당이 나오면 반드시 전체 이온 수 ÷ 혼합 용액 부피로 다시 계산합니다. 전체 이온 수가 일정해도 부피가 늘면 단위 부피당 이온 수는 감소합니다.

단위 부피당 이온 수 = 이온 수 ÷ (V산 + V염기)

언제? 보기 판별 마지막 단계에서 항상 (02, 03, 06)
