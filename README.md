# Cho's TEST — 세브란스 오케스트라 파트 연습기

오케스트라 총보(MIDI/MusicXML)에서 **내 파트만 뽑아 들으며 박자를 잡는** 연습 도구.
콘트라베이스 기준으로 만들었고, 악기는 얼마든지 늘릴 수 있다.

## 두 가지 실행 방법

### 1) 인터넷에 올려서 어디서나 쓰기 (권장)

`docs/` 폴더가 **서버 없이 그대로 도는 완성된 웹사이트**다. 아무 정적 호스팅에나 올리면 된다.

**GitHub Pages 로 올리기** (가장 간단, 무료):

```bash
cd "/Users/choseungwon/Desktop/오케스트라 앱"
git add -A && git commit -m "파트 연습기"
gh repo create orchestra-practice --public --source=. --push
```

그다음 GitHub 저장소 → **Settings → Pages** → Source 를 `main` 브랜치의 `/docs` 폴더로 지정.
몇 분 뒤 `https://<아이디>.github.io/orchestra-practice/` 로 **어느 기기·어느 네트워크에서든** 접속된다.

> `gh` 명령이 없으면 <https://cli.github.com> 에서 설치하거나,
> GitHub 웹에서 새 저장소를 만든 뒤 `docs/` 폴더를 끌어다 올려도 된다.
> Netlify Drop(<https://app.netlify.com/drop>)에 `docs` 폴더를 끌어놓으면 1분 만에 주소가 나온다.

### 2) 내 컴퓨터에서 실행 (곡을 추가할 때)

```bash
bash run.sh
```

`http://localhost:8000` 접속. 같은 와이파이의 폰에서도 열리도록 IP를 함께 표시한다.

> ⚠️ 학교·병원 같은 기관 와이파이는 기기끼리 통신을 막아 놓은 경우가 많다.
> 그럴 땐 **폰 핫스팟을 켜고 맥을 거기에 연결**하면 된다.

## 곡 추가하기

1. `bash run.sh` 로 로컬 실행 → **새 곡 추가** 열기
2. 오케스트라 **MIDI 또는 MusicXML** 파일 선택 → **트랙 분석**
3. 트랙 목록에서 내 파트 선택 (콘트라베이스는 자동 추천) → 제목·분류 입력 → 저장
4. 인터넷 배포판에도 반영하려면:

```bash
.venv/bin/python build_static.py     # docs/ 다시 굽기
git add -A && git commit -m "곡 추가" && git push
```

### 악보를 어디서 구하나

- **[markGotham/hauptstimme](https://github.com/markGotham/hauptstimme)** — 베토벤 교향곡 1~9번,
  하이든·브람스·브루크너·슈베르트 등 오케스트라 총보 MusicXML (MIT/CC0). **여기 있는 곡이 가장 정확하다.**
- **[MuseScore.com](https://musescore.com)** — 이용자들이 올린 총보가 많다. 곡 페이지에서
  MusicXML(또는 MIDI)로 내려받아 이 앱에 넣으면 된다.
- MuseScore·시벨리우스 등 악보 프로그램에서 **MusicXML 내보내기** 한 파일도 그대로 쓸 수 있다.

> **프로메테우스 서곡(Op.43)·피아노 협주곡 3번(Op.37)** 은 위 CC0 저장소에 없다(교향곡만 수록).
> 무료 MIDI 사이트에도 올라와 있지만 **누가 만든 시퀀스인지·재배포해도 되는지가 불분명**해서
> 공개 사이트에 함께 올리지 않았다. MuseScore 등에서 총보 파일을 받아
> **새 곡 추가**로 넣으면 다른 곡과 똑같이 동작한다.
> (오케스트라 총보를 받아야 한다. 피아노 편곡본에는 콘트라베이스 성부가 없다.)

## 기능

| | |
|---|---|
| **파트 연습** | 곡 선택 → 내 파트만 재생. 10초 앞뒤 이동, 탐색바, 속도 40~120% |
| **메트로놈(단독)** | 곡과 무관하게 켜는 메트로놈. 인1~인6, 보조 클릭, 탭 템포 |
| **원곡 듣기** | 곡마다 유튜브 링크를 저장해 두면 플레이어가 함께 뜬다 |
| **성부 분리** | 첼로+베이스 2단 악보에서 베이스만 분리 (첼로 포함 토글) |
| **큐 음표 제외** | 파트보에 인쇄된 다른 악기 큐를 자동으로 걸러냄 |
| **실음 8vb** | 콘트라베이스 실제 소리 높이(한 옥타브 아래)로 듣기 |
| **WAV 저장** | 내 파트를 음원 파일로 내보내기 |

단축키 — `스페이스` 재생/정지, `←` `→` 10초 이동, 메트로놈 탭에서 `T` 탭 템포, `↑` `↓` BPM

## 구성

```
server.py            로컬 서버 + 악보 해석 (music21)
app.js  index.html   화면과 재생 로직 (Tone.js)
style.css            디자인
library/             변환해 둔 곡 데이터
docs/                인터넷 배포용 정적 사이트  ← build_static.py 가 만듦
scores/              내려받은 원본 악보(MusicXML)
build_static.py      docs/ 굽기
import_beethoven.py  베토벤 교향곡 1번 등록 예시
```

### 재생 타이밍이 정확한 이유

악보의 **템포 변화·도돌이표·다 카포**를 모두 펼쳐서, 각 음표를 "정상 속도에서 몇 초"인지로
미리 계산해 둔다. 재생기는 그 초를 그대로 쓰고 속도 배율만 곱하므로,
느린 서주 → 빠른 본론 같은 구조가 실제 연주처럼 재생된다.

## 알려진 한계

- PDF 파트보(악보 이미지 인식) 경로는 정확도가 낮아 **MIDI/MusicXML 사용을 권장**한다.
- 원본 악보에 반복 표시가 빠져 있으면 그만큼 짧게 재생된다 (예: 교향곡 1번 2악장).
- 합성 음원이라 실제 연주의 루바토와는 자동으로 맞춰지지 않는다.
